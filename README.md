mas-cn 是 Microsoft-Activation-Scripts 的完整中文本地化版本，面向需要在 Windows 与 Office 环境下执行激活流程的技术用户。该工具保留了原项目的全部激活机制，包括 HWID、Ohook、TSforge、KMS38 及在线 KMS，并针对中文界面显示与远程脚本调用场景进行了兼容性调整。脚本采用模块化设计，各激活方式在持久性、离线可用性与硬件变更适应性方面具备不同特性，用户可依据具体部署环境选择相应方案。本地化工作涵盖翻译校对、编码适配及执行逻辑校验，确保在保持原有功能完整性的前提下提供一致的操作体验。

## ✅ Requirements

- **OS:** Windows 10 / 11
- **Shell:** PowerShell 5.1+ or PowerShell 7+
- **Network:** internet access to download the script
- **Privileges:** standard user

## Features

- 完整中文本地化：菜单、提示信息、错误输出与日志文本均以简体中文呈现，降低中文用户的操作门槛与误读风险。

- 多激活方式并存：集成 HWID、Ohook、TSforge、KMS38 与在线 KMS 等激活路径，可根据系统版本与授权需求选择对应方案。

- 激活状态自检：内置检测逻辑，可在激活前后查询当前 Windows 与 Office 的授权状态，便于确认结果。

- 高级故障排除：提供针对常见激活失败的诊断与修复流程，涵盖残留授权清理、服务状态检查与激活信息重建。

- 中文显示兼容处理：对脚本输出进行编码与字符集适配，避免中文环境下出现乱码或截断。

- 远程执行支持：针对 IRM 远程调用场景进行脚本适配，可直接在 PowerShell 或终端中完成调用与执行。

- 版本同步维护：跟随上游版本迭代更新，并提供变更记录以便追溯本地化差异与修订内容。

- 无侵入式设计：激活过程不修改系统镜像文件，部分激活方式在硬件变更或功能升级后仍可维持激活状态。

- 开源许可：遵循 GPL-3.0 协议分发，允许修改与再分发，但需保留出处说明或提供源码获取途径。

## How it works

mas-cn 以脚本化方式封装底层激活逻辑，将用户交互、参数解析与实际激活操作分离。运行入口脚本后，工具首先检测当前操作系统版本与已安装的 Office 产品，枚举可用的激活通道，并以交互式菜单呈现选项。用户选择激活方式后，脚本按对应方法生成激活所需的数据，调用系统内置的授权管理组件完成安装与提交，随后读取授权状态并向用户反馈结果。

对于 HWID 方式，工具在本地计算与当前硬件绑定的票据，将其写入系统的激活存储区，使激活状态在硬件不变的前提下持久保留，并可在同型号硬件的重装或功能升级后自动恢复。Ohook 方式通过在本地挂载钩子拦截 Office 的授权校验流程，无需修改系统激活存储即可让 Office 进入已激活状态，且在硬件变更后仍然有效。TSforge 系列方式则直接操作激活数据库中的记录，其中 ZeroCID 与 StaticCID 变体可写入不依赖联网的永久记录，KMS4k 变体将有效期延长至远期时间点。在线 KMS 方式通过连接 KMS 服务完成周期性续期，每次有效期为 180 天。

所有激活操作均在本地完成，工具不收集、不上传任何设备信息或使用数据。脚本在执行前会进行环境自检，包括权限检查、系统组件可用性验证以及残留状态清理，以降低冲突与失败概率。各激活方式的日志与返回值统一汇总，便于在出现异常时定位具体环节。工具本身不修改系统核心文件，不驻留后台进程，激活完成后即可退出，不改变机器的硬件标识。

## Compatibility

mas-cn 基于 MAS 原版脚本进行汉化与本地化适配，其运行环境要求与原版保持一致，同时对中文 Windows 环境做了针对性验证。

**操作系统支持**

- Windows 10 与 Windows 11 全版本（含各年度功能更新版本），推荐使用最新累积更新以获得最佳兼容性。
- Windows 8 / 8.1 受支持，但部分激活方式（如 HWID）不可用，具体可用性取决于所选激活方法。
- Windows 7 受支持，需通过 PowerShell 兼容方式调用脚本，且可用激活方法受限。

**Office 支持**

- 支持 Office 2013 及以上版本，包括 Office 2016、2019、2021 与 Microsoft 365。
- 支持 Click-to-Run 与 MSI 两种安装形态，具体可用激活方式随 Office 版本与安装类型而异。

**运行环境要求**

- Windows PowerShell 5.1 或更高版本；Windows 7 环境需确保 .NET Framework 与 PowerShell 版本满足脚本运行条件。
- 终端（Windows Terminal）与经典控制台均可正常运行，脚本输出已针对中文编码做兼容处理，避免出现乱码。
- 需要具备管理员权限，激活操作涉及系统授权组件与注册表写入。

**中文环境适配**

- 脚本界面、提示信息与错误输出均为简体中文，并对中文路径、中文用户名等场景做了兼容性处理。
- 已适配 IRM 远程调用方式，在中文区域设置下可正常拉取并执行脚本。

**激活方式兼容性说明**

- 不同激活方式对系统版本、Office 版本及硬件环境的支持范围不同：HWID 与 TSforge 系列主要面向 Windows 10 / 11；Ohook 与在线 KMS 对 Office 版本覆盖更广。
- 部分方式在硬件变更、系统重装或功能升级后的激活保持能力存在差异，选择前应结合使用场景评估。
- 在启用了受控文件夹访问、第三方安全软件或组策略限制的环境中，脚本可能被拦截，需提前调整相关策略。

**已知限制**

- Windows Defender 存在误报可能，建议在执行前临时关闭实时扫描。
- 在精简版系统、修改版系统或非标准授权环境中，激活结果可能不符合预期。
- 脚本不修改系统镜像与安装介质，兼容性表现取决于目标系统自身的授权组件完整性。

## FAQ

**汉化版与官方原版有哪些差异？**
mas-cn 在保持激活脚本逻辑与官方原版一致的前提下，完成了界面文本、菜单选项、提示信息与错误输出的中文本地化，并针对中文显示环境做了字符编码兼容处理。脚本还调整了远程调用方式，使其能够在 IRM 远程使用场景下正常加载与运行。激活机制本身未作改动，因此激活结果与官方版本保持一致。

**支持哪些激活方式？**
本工具集成了 HWID、Ohook、TSforge（含 ZeroCID、StaticCID 与 KMS4k 模式）以及在线 KMS 等多种激活途径。不同方式在持久性与适用场景上存在差异：HWID 与 TSforge 的 ZeroCID / StaticCID 模式可实现永久激活；在线 KMS 与 KMS4k 模式则为周期性激活，需要定期续期。用户可根据目标系统版本与使用需求选择合适的方式。

**激活后是否需要保持后台进程或残留文件？**
不需要。HWID 与 TSforge 系列方式不会在系统中留下用于维持激活状态的常驻文件或服务。在线 KMS 方式则依赖计划任务在到期前自动续期，属于设计上的正常行为，而非额外驻留。

**硬件变更或系统重装后激活是否仍然有效？**
不同方式表现不同。Ohook 与在线 KMS 在硬件变更后仍可保留激活状态；HWID 与 TSforge 的 KMS4k 模式则与硬件绑定，硬件更换后需重新执行激活。对于同一硬件上的全新安装，HWID 方式可自动恢复激活，而其他方式通常需要重新运行脚本。Windows 10 / 11 的功能升级一般不会影响 HWID、Ohook 与在线 KMS 的激活状态。

**运行时被安全软件拦截应如何处理？**
由于脚本涉及系统激活相关操作，部分安全软件可能将其识别为风险行为并触发拦截或误删。建议在运行前将相关文件加入排除列表，或临时关闭实时扫描，完成后再恢复防护设置。请仅从本项目提供的可信来源获取脚本，避免使用被篡改的副本。

**是否支持离线环境使用？**
支持程度取决于所选激活方式。HWID、TSforge 的 ZeroCID 与 StaticCID 模式，以及 KMS4k 模式均可在离线状态下完成激活；Ohook 与在线 KMS 则需要网络连接以完成验证或续期流程。在受限网络环境中，应优先选择离线可用的方式。

**中文显示出现乱码或提示信息异常怎么办？**
本汉化版已针对中文编码做兼容处理。若仍出现乱码，通常与终端代码页设置或宿主环境字体有关。可尝试在支持 UTF-8 的终端中运行，或调整系统区域与语言设置后重试。如问题持续存在，请记录终端类型与系统版本信息以便排查。

**使用本工具需要满足哪些前提条件？**
需要具备管理员权限以执行激活相关操作，目标系统应为受支持的 Windows 或 Office 版本。运行前应确认系统时间与区域设置正确，避免因时间偏差导致验证失败。具体兼容范围请参考本项目的兼容性说明。

**本项目与官方原版之间是什么关系？**
mas-cn 是官方 MAS 项目的中文本地化衍生版本，遵循 GPL-3.0 许可证分发。脚本核心逻辑来源于官方项目，汉化与兼容性调整由本项目维护。修改或再分发代码时，请遵守许可证条款，标明来源或提供获取源代码的途径。
